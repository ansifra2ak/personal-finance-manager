
# Personal Finance Manager

## Project Overview
A command-line Personal Finance Manager developed using Python.
It helps users record, store, view, and analyze daily expenses.

## Features
- Add new expenses
- Store expenses using CSV
- View saved expenses
- Generate category-wise spending reports
- Calculate total and average spending
- Create and restore expense backups
- Validate user input
- Handle errors

## Technologies Used
- Python 3
- CSV module
- Object-Oriented Programming (OOP)
- datetime
- collections
- shutil
- os

## Project Structure
- main.py - Main application and menu
- expense.py - Expense class and validation
- storage.py - CSV file operations
- reports.py - Expense analysis
- backup.py - Backup and restore

## How to Run
1. Install Python 3.
2. Open the project folder in a terminal.
3. Run:

    python main.py

4. Follow the interactive menu.

## Sample Usage
1. Select Add Expense.
2. Enter amount, category, date, and description.
3. View saved expenses.
4. Generate an expense report.
5. Create or restore backups.
